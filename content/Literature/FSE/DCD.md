## ++ Stuff

- Data Types
- Visibility:
	- `+` Public
	- `-` Private
	- `#` Protected
	- `~` Packaged
- Getters / Setters
- Constructors and Destructors
- Extra
	- attributes, operations, classes

## Added Syntax

- To specify a package draw a boundary and write the package name at the top left of the boundary.
