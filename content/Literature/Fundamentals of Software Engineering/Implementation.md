## Good Programming Practices

> General practices to be followed.
> Improves the quality of code.

- Readability
	- Indentation
	- Proper Line Length
- Comments
	- Comment before coding
	- Comment for every non trivial function
- Naming
	- Variable names
		- Meaningful
		- Consistent
- DRY
	- Don't Repeat Yourself
- Reuse
- Don't Hardcode Values
